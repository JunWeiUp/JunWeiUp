# Profile maintenance

`README.md` is the English profile shown by default on `github.com/JunWeiUp`. `README.zh-CN.md` is the Simplified Chinese version. Update both files when changing the introduction or project links.

The language links sit above the banner. The Chinese link opens the translated README in this repository; its English link returns to the profile. GitHub renders only `README.md` on the profile and strips scripts, so this is page navigation, not an in-place language toggle. GitHub's navigation, sidebar bio, and native profile sections are outside the README language switch.

## Images

The banner, information cards and project cards are original SVG assets generated by `scripts/build_assets.py`, with English and Simplified Chinese copy in light and dark variants. English assets use names such as `header-light.svg`; Chinese assets use `header-zh-CN-light.svg`. Edit the localized copy in the script and rebuild both languages together. They contain no JavaScript, external fonts or tracking. The Clipy screenshot comes from `JunWeiUp/Clipy/res/search.png`; it shows the actual Chinese UI and is shared by both versions.

```sh
python3 scripts/build_assets.py
```

## Public data snapshot

The statistics card is a dated snapshot, not a live counter. It counts public repositories, public non-fork repositories, and stars received by public non-fork repositories. Non-fork does not imply that all code in a repository is original. Private repositories and contributions are not queried or displayed.

To refresh from GitHub's public API and rebuild the images:

```sh
python3 scripts/build_assets.py --refresh
git add profile-data.json assets/
git commit -m "Refresh public profile snapshot"
git push
```

No third-party statistics image service or scheduled workflow is required. The reference for the introduction / statistics / selected-project structure was [Anurag Hazra's profile](https://github.com/anuraghazra). Its artwork and copy were not reused.
